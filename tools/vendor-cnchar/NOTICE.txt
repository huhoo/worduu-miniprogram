Vendored data from cnchar (https://github.com/theajack/cnchar), MIT licensed.

Files:
  stroke-order-jian.json  per-character stroke type codes (6,939 characters, simplified)
  stroke-order-trad.json  per-character stroke type codes (2,611 characters, traditional)
  stroke-table.json       stroke code -> standard name / shape / type / foldCount
  LICENSE                 the upstream MIT licence, redistributed unaltered

The two order tables are near-disjoint: they share only 46 characters, and on those 46
they agree exactly, so a character is looked up in the simplified table first and falls
back to the traditional one.

Used by scripts/build-stroke-data.mjs to attach standard stroke NAMES to the
centrelines it takes from hanzi-writer-data. The two datasets are independent;
a character only gets names when both agree on its stroke count.
